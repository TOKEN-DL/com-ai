# com-ai

## Agent skills

### Issue tracker

Issues and specs are tracked in GitHub Issues for `TOKEN-DL/com-ai` via the `gh` CLI. See `docs/agents/issue-tracker.md`.

### Triage labels

Five canonical triage roles map to identically named GitHub labels: `needs-triage`, `needs-info`, `ready-for-agent`, `ready-for-human`, `wontfix`. See `docs/agents/triage-labels.md`.

### Domain docs

Single-context layout: one `GLOSSARY.md` at the repo root and system-wide ADRs in `docs/adr/`. See `docs/agents/domain.md`.
